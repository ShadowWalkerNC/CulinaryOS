# CulinaryOS UI & Theme Customizer Engine

Universal design system tokens, color palettes, dark/light/OLED modes, and real-time CSS variable bindings for React, Vite, Next.js, and all Antigravity frontend applications.

## Supported Theme Presets

- Classic Bistro (Light): #0f172a / #f8f9fa - Warm linen, elegant fine dining
- Midnight Slate (Dark): #f8fafc / #090d16 - Deep navy slate, cyan accents
- Kitchen OLED: #fbbf24 / #000000 - 100% True Black, high-heat neon amber & emerald for KDS
- Cyberpunk Neon: #06b6d4 / #050510 - Electric cyan, neon magenta
- Botanical Garden: #047857 / #f4fbf7 - Forest green, sage, warm cream
- Bordeaux & Wine: #e11d48 / #120b0e - Burgundy, rose gold

## How to Use

Import ThemeProvider and ThemeCustomizer from @culinaryos/ui.
