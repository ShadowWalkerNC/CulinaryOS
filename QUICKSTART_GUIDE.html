🚀 How to Start in 1 Click (Cross-Platform)

CulinaryOS is 100% sovereign and turnkey. Choose your operating system below to launch:

🪟
Windows 10 / 11
Double-click START_HERE.bat in this folder. It auto-installs Node.js/pnpm, builds engines, and boots all services.
🍎
macOS / Linux
Open Terminal in this folder and run ./START_HERE.sh (or bash START_HERE.sh).
📱
Tablets & Handhelds
Open your computer's local Wi-Fi IP (e.g. http://192.168.1.x:5172) on any iPad, phone, or kitchen TV display.
📡 Connecting iPads, Mobile POS & Kitchen Screens Over Local Wi-Fi:

All servers bind to 0.0.0.0 with dynamic LAN API routing. If Windows Firewall blocks incoming connections from other devices, double-click scripts/setup-firewall.bat to allow CulinaryOS ports with 1 click.
